Техническое задание: Разработка AI-исследователя (Market Researcher Agent)
Цель задания: Создать минимально жизнеспособную мультиагентную систему (или систему с Tool Use), которая собирает данные о компании, анализирует их и формирует итоговый аналитический отчет.
Время на выполнение: 2–4 часа.
Стек: На свой выбор (к примеру, Node JS / Python). В задании будут примеры для python. 
Разрешено использовать любые фреймворки (CrewAI, LangGraph, чистый OpenAI/Anthropic API, Autogen) на свой выбор.
________________________________________
1. Архитектура системы и инструменты
Вам необходимо реализовать агента (или группу агентов), у которого есть доступ к двум инструментам (Tools). Инструменты должны обращаться к реальным внешним источникам данных (API), а не возвращать фиктивные значения:
1.	get_company_profile(company_name: str) -> str
1.	Что делает: Возвращает краткое описание компании и сферу деятельности.
2.	Реализация: Получить реальные данные через библиотеку yfinance (поля: longBusinessSummary, sector, industry, country, fullTimeEmployees, marketCap). В качестве fallback — Wikipedia REST API (https://en.wikipedia.org/api/rest_v1/page/summary/{company_name}). Если компания не найдена ни в одном источнике — вернуть информативное сообщение об ошибке.
2.	get_financial_news(company_name: str) -> list[str]
0.	Что делает: Возвращает список последних 2-3 новостей о компании.
1.	Реализация: Получить реальные новости через Tavily Search API (pip install tavily-python). Запрос: "{company_name} financial news", max_results=5, возвращать заголовок + краткое содержание каждой статьи. Бесплатная альтернатива — Google News RSS через feedparser (URL: https://news.google.com/rss/search?q={company_name}+stock). Ключ Tavily указывается в .env как TAVILY_API_KEY.
________________________________________
2. Задача Агента
На вход системе подается текстовый запрос: например, "Составь аналитический отчет по компании Apple".
Алгоритм работы агента:
1.	Понять, по какой компании нужен отчет.
2.	Вызвать инструмент get_company_profile.
3.	Вызвать инструмент get_financial_news.
4.	Собрать все данные вместе, проанализировать их (выявить позитивные и негативные факторы).
5.	Выдать строго структурированный финальный отчет в формате Markdown.
Требования к финальному отчету:
•	Название компании и сфера деятельности.
•	Краткий анализ последних новостей (что хорошего, что плохого).
•	Итоговый вывод: краткосрочные перспективы компании.
________________________________________
3. Требования к реализации (Что мы оцениваем)
•	Осознанный выбор инструмента: Агент не должен вызывать функции наугад. Он должен четко понимать, зачем он их вызывает.
•	Корректный Tool Calling: Передача правильных аргументов в функции (например, строка "Apple", а не весь исходный промпт пользователя).
•	Обработка ошибок (Edge Cases): Что произойдет, если пользователь введет "Составь отчет по компании Рога и Копыта"? (Инструмент вернет "Компания не найдена". Агент должен не упасть с ошибкой, а корректно ответить пользователю, что данных недостаточно).
•	Логирование (Traceability): В консоли должно быть четко видно шаги агента: "Думаю..." -> "Вызываю get_company_profile для Apple..." -> "Получил ответ..." -> "Формирую отчет...".

5. Источники реальных данных
5.1 Профиль компании — get_company_profile
Основной источник: yfinance (pip install yfinance). Использовать тикер компании или её название. Полезные поля: longBusinessSummary, sector, industry, country, fullTimeEmployees, marketCap, website. Установка: pip install yfinance.
Fallback: Wikipedia REST API. Endpoint: https://en.wikipedia.org/api/rest_v1/page/summary/{company_name}. Возвращает поле extract — краткое описание. Не требует API-ключа.
5.2 Новости компании — get_financial_news
Рекомендуемый источник: Tavily Search API (tavily.com, бесплатный тариф: 1000 запросов/месяц). Специально создан для агентских систем — возвращает структурированный текст без HTML-шума. Установка: pip install tavily-python. Переменная окружения: TAVILY_API_KEY.
Бесплатная альтернатива: Google News RSS. Библиотека feedparser (pip install feedparser). URL: https://news.google.com/rss/search?q={company_name}+stock&hl=ru. Не требует API-ключа, работает без ограничений. Поля: entries[i].title, entries[i].summary, entries[i].published.
5.3 Пример .env.example с ключами для реальных источников
OPENAI_API_KEY=sk-...      # или ANTHROPIC_API_KEY
TAVILY_API_KEY=tvly-...   # tavily.com — для get_financial_news
Если выбираете Google News RSS вместо Tavily — TAVILY_API_KEY не нужен. Это допустимо, но в README необходимо явно указать причину выбора.
